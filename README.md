## Brief Description 
1. Basic Single Inheritance – Demonstrates inheritance between a Person base class and Student derived class.
2. Protected Member Access – Shows how a derived class can access protected members of its base class.
3. Public vs Private Inheritance – Demonstrates the difference between public and private inheritance and member accessibility.
4. Multilevel Inheritance – Implements a three-level inheritance hierarchy: Person → Employee → Manager.
5. Hierarchical Inheritance – Demonstrates multiple derived classes (Car and Bike) sharing a common Vehicle base class.
6. Multiple Inheritance – Demonstrates a class inheriting from two base classes: Academic and Sports.
7. Multiple-Inheritance Ambiguity – Resolves ambiguity between identical functions of two base classes using the scope-resolution operator.
8. Constructor and Destructor Order – Demonstrates the order of constructor and destructor execution in inheritance.
9. Parameterized Base Constructor – Shows how a derived class initializes a parameterized constructor of its base class.
10. Function Overriding – Demonstrates overriding a virtual function in derived classes using virtual and override.
11. Abstract Class – Demonstrates an abstract class using a pure virtual function and derived class implementations.
12. Virtual Base Class – Uses virtual inheritance to solve the diamond inheritance problem and avoid duplicate base-class data.
13. Friend Class – Demonstrates how a friend class can access private members of another class.
14. Nested Class – Demonstrates creating and using a class defined inside another class.
15. Vehicle Rental System – Mini-project demonstrating inheritance, function overriding, and rental calculation for cars and bikes.
16. Employee Payroll System – Mini-project using an abstract class, inheritance, function overriding, and polymorphism to calculate employee salaries.
